The deployment makes NO requests to that mirror or any external package server.
Explicit Google font declarations additionally use Google's CSS metadata service
and download TrueType fonts directly in the browser from fonts.gstatic.com.
Their per-family licenses apply: https://fonts.google.com
The default pdfTeX path makes no Google font requests.
The reduced pdftex.map contains entries only for bundled fonts; the added
Latin Modern entries are from the upstream lm.map. Font files, package files
and format are unmodified. Asset hashes are in assets.sha256.json.
Only the subset documented in the Help dialog and README is supported.
